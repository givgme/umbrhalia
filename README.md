# Umbrhalia — sitio web

Sitio del proyecto Umbrhalia / Cazando Eclipses.

## Estructura
- `index.html` — página principal (presentación, Ohr, el proyecto, mapa y participación pendientes)
- `css/style.css` — estilos
- `assets/img/` — assets visuales (marca de Umbrhalia, ilustración de Ohr)

## Pendiente
- Mapa interactivo de trayectorias de eclipses 1900–2100 (requiere datos astronómicos reales)
- Formulario de participación
